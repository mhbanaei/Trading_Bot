# Agent notes

## Publishing snapshot: `RTC/`

`RTC/` is the commit-ready mirror of this project that gets pushed to GitHub.
It must never contain live credentials, databases or runtime output.

**Rule: after any change to `nobitex_bot/`, `scripts/`, `tests/`, `deploy/`,
`docs/`, `run.py`, `start.bat` or `README.md`, run**

```bash
python sync_rtc.py
```

and keep `RTC/` in sync in the same turn. Do not hand-edit files inside `RTC/`
except `.gitignore`; everything else is generated by `sync_rtc.py` and would be
overwritten.

Generated, safe to commit: `RTC/.gitignore`, `RTC/config.example.json`
(real `config.json` with the credential fields blanked).

Never copied into `RTC/`: the real `config.json`, `data/` (trading databases,
`data/real/credentials.json`, events), `logs/`, `screenshots/`, `.freebuff/`,
`.env*`, private keys. `sync_rtc.py` scans the result for the actual secret
values and exits non-zero instead of letting a leak through.

## Ground rules for this project

- Talking to a real exchange account: never assume a request succeeded —
  reconcile order status and balances (`nobitex_bot/execution.py`).
- Never print API keys, tokens, passwords or Authorization headers.
- `config.json` and `data/` are the user's live state: back up before any
  migration, never reset them.
- IRT and USDT market sections stay independent; no automatic conversion
  between them.
